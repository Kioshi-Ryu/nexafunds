# UI/UX Audit Notes

The desktop sign-in screen presents a clear split layout with strong visual hierarchy and legible account controls. The desktop Create Budget modal is focused, uses familiar form controls, and exposes the primary action clearly.

The mobile budget modal needs a tighter edge-to-edge sheet treatment and a more compact vertical rhythm. The refinement will make the mobile dialog occupy the intended full viewport width, reserve safe-area spacing, reduce unnecessary vertical space, and prevent overlay content from competing with the active form.

The audit also identified opportunities to improve keyboard escape behavior, visible focus states, disabled controls, surface hierarchy, and reduced-motion support. These improvements are included in the current styling pass.
